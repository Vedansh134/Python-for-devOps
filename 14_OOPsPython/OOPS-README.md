# Object-Oriented Programming (OOP) in Simple Language

- OOP is a way of designing and writing code that focuses on "objects" that have properties and behaviors. Think of it like real-world things:

- Objects = Things like a Car, Dog, or Bank Account.
- Properties = Details about the thing (Car: color, speed; Dog: breed, age; Account: balance).
- Behaviors = Actions the thing can do (Car: drive(); Dog: bark(); Account: deposit()).

Key OOP Concepts:
1. Class: A blueprint for creating objects (like a "Car" template).
2. Object: An actual thing made from the class (a red Toyota, a brown Labrador).
3. Inheritance: Objects get traits from "parent" classes (ElectricCar inherits from Car).
4. Encapsulation: Hiding inner details, showing only needed parts (Account hides balance logic).
5. Polymorphism: Same action, different ways (drive() in Car vs. ElectricCar).
