## condtions in python

- conditions are used to perform different actions based on different conditions. In Python, we use conditional statements to execute code blocks based on certain conditions.
- The main conditional statements in Python are `if`, `elif`, and `else`.

## Types of Conditions

- if statement : The simplest form, which runs a code block only if its condition is True.
- if-else statement : This allows for an alternative code block to run if the condition is False.
- if-elif-else statement : This allows for multiple conditions to be checked in sequence,executing the code block of the first True condition.
- nested if statements : An if or if-else statement inside another if or if-else statement.
- Ternary expression (one-liner) : A compact way to write an if-else statement in a single line.


### Comparison Operators
- Conditions use comparison operators to evaluate values :

| Operator | Meaning                     | Example   |
|----------|-----------------------------|-----------|
| `==`     | Equal to                    | `a == b`  |
| `!=`     | Not equal to                | `a != b`  |
| `>`      | Greater than                | `a > b`   |
| `<`      | Less than                   | `a < b`   |
| `>=`     | Greater than or equal to    | `a >= b`  |
| `<=`     | Less than or equal to       | `a <= b`  |

### Logical Operators
- Logical operators are used to combine multiple conditions :

| Operator | Meaning          | Example        |
|----------|------------------|----------------|
| `and`    | Logical AND      | `a > 0 and b > 0` |
| `or`     | Logical OR       | `a > 0 or b > 0`  |
| `not`    | Logical NOT      | `not(a > 0)`      |
